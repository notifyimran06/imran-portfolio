# Imran Hossain — Portfolio Website

## Files
- `index.html` — the complete responsive portfolio website (HTML, CSS, and JavaScript).
- `assets/profile.jpg` — the profile photo used on the homepage.

## Publish with GitHub Pages
1. Extract this ZIP file.
2. Open your GitHub repository (for a user site, name it `YOUR-USERNAME.github.io`).
3. Upload `index.html` and the entire `assets` folder (including `profile.jpg`) to the repository root.
4. Commit the changes.
5. In repository **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
6. Wait for GitHub Pages to publish, then open the URL shown in Settings → Pages.

Important: Keep `assets/profile.jpg` in the same folder structure. The HTML references the photo at that exact relative path.
